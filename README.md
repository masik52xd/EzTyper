## ✨ Key Features

* 📑 **Multi-tab interface:** Conveniently work with multiple text documents simultaneously.
* 🔢 **Line numbering:** Clear display of text and code structure.
* 🎨 **Flexible interface customization:**
* Support for color themes (e.g., *Nordic Dark*).
* Adjustable text margins (sides, top, bottom) in pixels.
* Customizable font and size settings for the preview window.
*   ⏱️ **Built-in Pomodoro Timer:** A tool for maintaining focus and managing work time.
* 💡 **"Idea of ​​the Day":** A generator for inspiration and quick note ideas.
* 🧹 **Text Cleaner:** Quickly clean and format text.
* 📖 **Reading Time Calculator:** Automatically estimates the time required to read the text aloud or silently.
* 👁️ **Live Preview (F5):** Real-time preview of the formatted text.
* At the moment only Ukrainian Language

---

## 🛠️ Tech Stack

* **Programming Language:** Python 3.x
* **GUI Framework:** PyQt6
